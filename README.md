# Cachd v0.1.0 — First Pre-release

The first public pre-release of Cachd, a Chromium-based desktop browser focused on offline web access and intelligent page preloading.

### Features
- Chromium-based browsing.
- Intelligent page prediction.
- Automatic page preloading.
- Offline Mode.
- Local storage and restoration of user-entered data between browser sessions.

### Platform
- Windows 10/11
- x64

### Installation
Download `Cachd-Setup-0.1.0.exe` and run the installer.

### Notes
This is an early pre-release intended for testing. Some features may be incomplete, and compatibility with different websites is not guaranteed.

Feedback and bug reports are welcome.
